# noval

Vue 3 + Vite + TypeScript starter.

## Requirements

- Node.js 20+ (or current LTS)
- npm

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Stack

- [Vue 3](https://vuejs.org/) (`<script setup>` + TypeScript)
- [Vite](https://vite.dev/)
- [vue-tsc](https://github.com/vuejs/language-tools) for type-checking on build
